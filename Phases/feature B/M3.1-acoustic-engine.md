# M3.1-acoustic-engine

**Read first:** `00-glossary.md`, `00-stack-and-conventions.md`, `00-data-protection-model.md`, `00-system-map.md`, handoffs of `M1.1`, `M1.2`, `findings/P0.2-findings.md` (verdict `<verdict>`, chosen audio library, model and runtime, thresholds, OS limits).

## Purpose

Build the production on-device acoustic engine inside `apps/mobile/src/edge/`: audio capture to an ephemeral ring buffer, local inference, threshold logic and construction of a de-identified flag object. It is the only code allowed to touch the microphone, and its tests prove nothing leaves.

## What already exists

- Foundation files and P0 findings (P0.2 prototype code in `prototypes/p0.2/`, never imported).
- From `M1.1` and `M1.2`: Expo dev build with the P0.2 native modules declared, the `src/edge/` folder with the import-isolation lint rule, auth and consent UI, Monitor Me tab locked or unlocked by consent.
- No engine logic, model assets or session UI.

## Scope

1. `src/edge/AudioSource`: wraps the capture library chosen in `P0.2`; exposes frames only to the ring buffer.
2. `src/edge/EdgeBuffer`: fixed-size ring buffer (default 10 s, 16 kHz mono; size from `P0.2`), preallocated typed array, overwritten continuously, `zeroFill()` on stop, on app background and on error.
3. `src/edge/Model`: loads the packaged ONNX/TFLite model from app assets; reports `model_version`; no network download of models at runtime.
4. `src/edge/Inference`: windowing, feature extraction and inference at the interval from `P0.2`; produces transient `InferenceResult` values that are never stored beyond the current window.
5. `src/edge/ThresholdEngine`: per-signature thresholds and smoothing (for example N of M windows), cool-down between flags, and a configurable cap on flags per session.
6. `src/edge/FlagBuilder`: the only exit from the module: builds a `DeIdentifiedFlag` matching the allow-list (signature, confidence rounded to 2 decimals, hour-truncated time bucket, model version, session id) and emits it through a narrow `onFlag` callback.
7. `src/edge/EdgeController` API for the app layer: `start({ sessionId, maxDurationSec })`, `stop()`, `status()` returning counters only (windows processed, flags emitted, running time).
8. Lifecycle: stop and zero the buffer when the app backgrounds, the screen locks (as limited by P0.2), on audio interruption, on headset removal if P0.2 found it unsafe, and when `maxDurationSec` elapses.
9. Ephemerality test suite (production versions of the P0.2 tests): import isolation lint, runtime spy, canary pattern, buffer zero-fill, payload shape.
10. Model assets and a model card: training data source, intended use, known limitations, false-trigger numbers from `P0.2`.

## Out of scope

- Session UI, consent flow integration and network sending (`M3.2`).
- Server endpoints (`B3.1`).
- Background listening beyond what `P0.2` permitted (decision: foreground-only).
- Speech recognition or any transcription.

## Contracts used

None. The engine never calls the network. The output flag type is a local TypeScript type that mirrors `DeIdentifiedFlagInput` from the contract (generated type imported **only** in `M3.2`, not inside `src/edge/`).

## Data model

In-memory only:

- `EdgeBuffer { samples: Float32Array | Int16Array, capacity, writeIndex, filled }`
- `InferenceResult { signature, score, windowIndex }` (transient)
- `ThresholdState { recentScores, lastFlagAtMs, flagsThisSession }`
- `DeIdentifiedFlag { signature, confidence, time_bucket, model_version, session_id }`
- No persistence, no storage, no files.

## Rules and behaviour

- Raw audio exists only inside `EdgeBuffer` and the model input tensor. No copies in any structure that outlives a call.
- `src/edge/` imports no network, filesystem, storage, analytics or logging module; the lint rule from `M1.1` is enforced in CI.
- Logging inside `edge/` is limited to counters and timings through a tiny `edgeMetrics` object with no audio-derived values.
- If the model fails to load, `start()` rejects with `EDGE_MODEL_UNAVAILABLE`; there is no cloud fallback.
- Microphone permission is requested at `start()` only, and released on `stop()`.
- A visible "listening" state is the app layer's responsibility, but `status()` must expose `isListening` truthfully and the engine refuses to run without a registered indicator callback.
- Flags are emitted only when thresholds are crossed; nothing is emitted otherwise.

## Acceptance checks

- [ ] Import-isolation lint: adding a forbidden import in `src/edge/` fails CI (show the failing run).
- [ ] Buffer test: after `stop()`, backgrounding, and error, all samples read zero (report 3 cases).
- [ ] Runtime spy test over a 10-minute synthetic session without threshold crossing: 0 network, filesystem and storage calls (report counts).
- [ ] Runtime spy test with 5 injected threshold crossings: exactly 5 flags emitted and no other outbound data (report counts).
- [ ] Canary test: pattern absent from heap snapshot after stop, storage directories, logs and the `onFlag` payloads (report what was scanned).
- [ ] Flag shape test: every emitted flag validates against the allow-list schema and has no extra properties (1,000 randomised runs).
- [ ] Inference latency p95 and battery per hour match or beat `P0.2` numbers on the named devices (report both).
- [ ] Nuisance-set re-run: triggers per hour at the chosen threshold within the `P0.2` limit (report the number).
- [ ] Lifecycle tests: background, interruption, `maxDurationSec` expiry each stop the engine and release the microphone (report 3 cases).
- [ ] Model card present with training data source and known limits.
