# M5.1-ephemerality-proof-and-polish

**Read first:** `00-glossary.md`, `00-stack-and-conventions.md`, `00-data-protection-model.md`, `00-system-map.md`, handoffs of `M1.1`, `M1.2`, `M2.1`, `M3.1`, `M3.2`, `B5.1`, and `findings/P0.2-findings.md`.

## Purpose

Make the headline claim, "raw audio never leaves the device", demonstrable and continuously tested in the finished app, and polish the mobile experience for the demo: battery, permissions, edge cases and release build.

## What already exists

- Foundation files and P0 findings.
- Mobile features: shell and auth (`M1.1`, `M1.2`), Radar (`M2.1`), acoustic engine (`M3.1`), Monitor Me session UX (`M3.2`).
- Per-feature ephemerality tests from `M3.1` and `M3.2`.
- Backend hardened in `B5.1`.

## Scope

1. **Proof suite in CI:** consolidate and run on every PR: import-isolation lint, runtime spy on network/filesystem/storage, canary pattern scan (heap, storage dirs, logs, outgoing payloads), buffer zero-fill, flag allow-list shape, microphone permission lifecycle.
2. **Full-flow canary run:** scripted end-to-end monitor session in the release build using an audio fixture with a unique canary pattern; capture all outbound traffic via a local proxy (for example mitmproxy) and assert the pattern and any audio-sized payload never appear.
3. **Native dependency review:** list every native module touching audio; for each, record version, what the source or documentation says about persistence/telemetry, and the test evidence; flag unknowns honestly.
4. **Privacy proof screen (demo):** a user-facing "How Ajna protects your audio" screen with live counters from `edgeMetrics` (windows processed, flags sent, bytes sent) and a plain-language explanation; no raw values.
5. **Battery and performance pass:** measure per-hour drain for a monitor session and for Radar usage on the named devices; tune thresholds/intervals within the `P0.2` limits.
6. **Permissions and edge cases:** denied/revoked microphone, interrupted audio, low battery (auto-stop below a configurable level), airplane mode, poor connectivity, app kill during a session (server session expiry handles cleanup).
7. **Polish:** loading/empty/error states, accessibility (screen reader, dynamic type, reduced motion), consistent wording, app icon/splash, EAS release build profile and install instructions.
8. **Wording and no-automatic-action sweep:** grep and manual screen review confirming "flagged for review" wording and crisis information panel presence.

## Out of scope

- New features.
- Background listening beyond the foreground-only decision.
- App store submission.
- Server changes except bug reports to `B5.1`.

## Contracts used

Reads `contracts/openapi.v1.yaml` (regenerated client). Publishes nothing. Any needed endpoint is a gap to report, not to invent.

## Data model

Client-side only: `edgeMetrics` counters (in memory), a `lowBatteryThreshold` setting in zustand (non-sensitive). No new persisted data.

## Rules and behaviour

- The proof suite must fail loudly: any outgoing request during a no-crossing session fails the build.
- Test fixtures are synthetic or licensed audio; no recordings of real people are committed.
- Proof statements in the UI must match tested reality; unknowns are stated as "not tested" in `docs/ephemerality-evidence.md`, not hidden.
- The app logs counters and timings only.

## Acceptance checks

- [ ] CI proof suite runs on PR and on release branch; show a green run and a deliberate-violation red run (for example adding a `fetch` in `edge/`).
- [ ] Full-flow canary: release build, 10-minute session, proxy capture shows 0 audio-sized or canary-containing payloads; list all captured requests with sizes (report).
- [ ] Heap/storage/log scan after session shows no canary pattern (report what was scanned and tool used).
- [ ] Native dependency review table complete for each audio-touching module (report count and unknowns).
- [ ] Battery per hour measured for monitor session and Radar on named devices; compare to `P0.2` (report numbers).
- [ ] Edge-case matrix executed: permission denied, interruption, low battery auto-stop, airplane mode, app kill; expected vs actual (report 5 rows).
- [ ] Privacy proof screen counters match the proxy capture (bytes sent equals captured bytes within 5%).
- [ ] Accessibility: screen reader walkthrough of all tabs on both platforms (report result); reduced motion verified.
- [ ] Wording sweep: banned-word grep 0; crisis panel and advisory sentences present on required screens (checklist).
- [ ] Release build installs from the EAS artifact on the named devices (report build ids).
- [ ] `docs/ephemerality-evidence.md` written with claims, tests, results and stated limitations.
