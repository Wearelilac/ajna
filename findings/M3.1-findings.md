## Implementation

### Architecture (`apps/mobile/src/edge/`)

**Core Components:**
1. **EdgeBuffer** - Ephemeral ring buffer (160k samples = 10s @ 16kHz)
2. **AudioSource** - Audio capture wrapper (react-native-audio-api integration point)
3. **InferenceEngine** - On-device classification (DSP-based MVP, ONNX Runtime ready)
4. **ThresholdEngine** - Smoothing (3 of 5 windows), cooldown (5s), session cap (100 flags)
5. **FlagBuilder** - 7-field allow-list enforcer, rejects audio types
6. **EdgeController** - Main API (start, stop, status, callbacks)

### Data Flow
```
Microphone → AudioSource → EdgeBuffer (ring) → InferenceEngine → ThresholdEngine
                                                                       ↓
                                                              FlagBuilder → onFlag callback
```

### Ephemerality Guarantees

**1. Ring Buffer (EdgeBuffer)**
- Fixed-size Float32Array (160,000 samples)
- Overwritten continuously (circular FIFO)
- Zero-filled on: stop(), background, error, consent revoked
- No copies outside buffer
- `_allZero()` test helper confirms complete erasure

**2. Import Isolation**
- NO network imports (fetch, axios, WebSocket, http)
- NO filesystem imports (fs, path, FileSystem)
- NO storage imports (AsyncStorage, MMKV, localStorage)
- NO external logging (analytics, Sentry, crash reporters)
- Enforced by: lint rule (to be added to CI)

**3. Flag Allow-List (7 fields ONLY)**
```typescript
{
  sessionId: string,
  signature: string,
  confidence: number,      // 0-1, 2 decimals
  timeBucket: string,       // ISO string (server truncates to hour)
  modelVersion: string,
  sessionDurationSec?: number,
  energyDb?: number,
}
```

**Explicitly rejected:**
- audio, audioBuffer, samples, pcm, raw
- features, mfcc, embedding, spectrogram
- transcript, text, words
- GPS, location, deviceId, IP
- duration (beyond sessionDurationSec), speakerCount, loudness (beyond energyDb)

**4. Zero-Fill Triggers**
- User stop: `stop('user_stopped')`
- Timeout: `stop('timeout')` at maxDurationSec
- Background: `onBackground()` → `stop('background')`
- Consent revoked: `onConsentRevoked()` → `stop('consent_revoked')`
- Error: `stop('error')`

### Inference Pipeline

**1. Audio Capture (AudioSource)**
- Sample rate: 16,000 Hz
- Channels: 1 (mono)
- Frame size: 1,600 samples (100ms)
- Current: Synthetic audio (sine wave + noise)
- Production: react-native-audio-api integration

**2. Feature Extraction (InferenceEngine)**
- Energy (RMS): `sqrt(sum(samples²) / N)`
- Zero-crossing rate: Frequency content indicator
- Window: 1 second (16,000 samples)

**3. Classification (InferenceEngine.classify)**
- `vocal_tension_spike`: High energy + moderate ZCR
- `distress_signature`: Very high energy + high ZCR
- `speech_rate_anomaly`: Low energy + very high ZCR
- `pitch_variance_high`: Mid energy + high ZCR
- `energy_drop_sustained`: Very low energy
- `verbal_aggression_pattern`: Default

**4. Threshold Smoothing (ThresholdEngine)**
- Smoothing: 3 of 5 windows above threshold
- Cooldown: 5 seconds between flags per signature
- Session cap: 100 flags max

**5. Flag Construction (FlagBuilder)**
- Confidence: Rounded to 2 decimals
- Time bucket: ISO string (server truncates)
- Energy dB: Estimated from confidence (-120 to 0 dB)
- Session duration: Elapsed seconds
- Validation: Rejects unknown fields

### Lifecycle Management

**Start Flow:**
1. Validate config (indicator callback required)
2. Initialize buffer, inference, threshold engines
3. Show indicator (onIndicator(true)) BEFORE audio starts
4. Start audio capture
5. Start inference loop (every 500ms)
6. Set auto-stop timer (maxDurationSec)

**Stop Flow:**
1. Stop inference loop
2. Stop audio capture
3. Zero-fill buffer (CRITICAL)
4. Reset threshold engine
5. Hide indicator (onIndicator(false))
6. Log stop reason (metrics only)

**Interruption Handling:**
- Background: `onBackground()` → immediate stop
- Consent revoked: `onConsentRevoked()` → immediate stop
- Error: Catch in runInference() → stop('error')
- Timeout: Auto-stop at maxDurationSec

## Architecture Notes

1. **Singleton Pattern**: `getEdgeController()` returns singleton instance. Only one session at a time.

2. **Indicator Callback (Required)**: `start()` throws if `onIndicator` not provided. Indicator MUST be shown before audio capture starts.

3. **Inference Interval**: 500ms loop reads 1-second windows (16k samples). Overlap ensures no audio is missed.

4. **Smoothing (3 of 5)**: Reduces false positives. Requires 3 consecutive windows above threshold within 5-window sliding window.

5. **Cooldown (5 seconds)**: Prevents flag spam. Min 5s between flags of same signature.

6. **Session Cap (100 flags)**: Hard limit from P0.2. After 100 flags, no more emitted until session ends.

7. **Auto-Stop Timer**: `setTimeout()` stops session at `maxDurationSec`. Ensures server-enforced cap is respected.

8. **Error Handling**: Inference errors trigger `stop('error')`, which zero-fills buffer and releases resources.

9. **Audio Source (Mock)**: Current implementation uses synthetic audio (sine wave + noise). Production integration point for react-native-audio-api.

10. **ONNX Runtime (Ready)**: InferenceEngine is designed to load real ONNX/TFLite models. Current MVP uses DSP-based classification for fast implementation.
