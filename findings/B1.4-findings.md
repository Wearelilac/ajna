## Design Summary

### BullMQ Setup
```typescript
// Queue for baseline computation
const baselineQueue = new Queue('ajna.wearable.compute-baseline', {
  connection: redis,
  defaultJobOptions: { attempts: 3, backoff: { type: 'exponential', delay: 2000 } }
});

// Processor
baselineQueue.process(async (job) => {
  const processor = new BaselineProcessor(...);
  await processor.process(job.data, db);
});
```

### Event Flow
```
Wearable metrics arrive (B2.1)
  ↓
Validate + store in vault
  ↓
Enqueue: ajna.wearable.compute-baseline { subjectId, date }
  ↓
BullMQ processor picks up job
  ↓
Call scoring service
  ↓
Store baselines + flags in vault
  ↓
If deviation detected → Create flag
  ↓
Job complete
```

### Scoring Service Integration
```
POST /v1/score/baseline
  input: { subject_id, metrics_date }
  returns: { baselines, deviation_flags, pri }

Uses: scoring_url + token from env
Timeout: 30s per job
Retry: 3 attempts with backoff
```
