## 2. Complementary Suppression

### Problem
**Primary suppression** blocks cells with <10 subjects, but arithmetic can recover small cells:
- If `total=15` and `group_A=13`, then `group_B=2` (inferable)

### Solution: Complementary Suppression Algorithm

**Step 1:** Identify marginally unsafe cells
```sql
-- Find cells where (N - suppressed_count) < K
SELECT
  community_id,
  week_start,
  SUM(CASE WHEN subjects_n >= 10 THEN subjects_n ELSE 0 END) AS released_sum,
  COUNT(*) FILTER (WHERE subjects_n < 10) AS suppressed_count,
  SUM(subjects_n) AS total
FROM community_week_agg
GROUP BY community_id, week_start
HAVING (SUM(subjects_n) - SUM(CASE WHEN subjects_n >= 10 THEN subjects_n ELSE 0 END)) < 10;
```

**Step 2:** Suppress complementary cells
```typescript
// If inferrable cell exists, suppress largest released cell in group
if (total - releasedSum < K) {
  const largestCell = findLargestCell(releasedCells);
  suppressCell(largestCell);
}
```

**Implementation Location:**
- `apps/api/src/workers/population-aggregation.processor.ts`
- Add post-aggregation complementary suppression pass
- Test with synthetic data (seeded small cells)
